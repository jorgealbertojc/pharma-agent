# 1.0.1 – Patch release with breaking change

> ⚠️ **BREAKING CHANGE**: The main source directory has been renamed from `src/` to `app/`. This may affect existing scripts, imports, or deployments that reference `src` explicitly. Please update your references accordingly.

## What's changed

### Refactor
- **Renamed `src/` to `app/`** for a cleaner and more intuitive entrypoint (`python -m app`).
- Updated all imports (`from src.` → `from app.`) across the codebase, tests, and documentation.
- Added `app/__main__.py` to allow direct execution of the package (`python -m app`).

### Fixes
- Fixed `RuntimeWarning` about module reload in `app.agent.__init__.py` by using lazy imports.
- Added `uvicorn` as an optional dependency for API (now required when using `--api`).

### Documentation
- Updated `README.md` to reflect the new entrypoint and usage examples.
- Added migration note for users upgrading from previous versions.

### Dependencies
- No new production dependencies; `uvicorn` is now listed as a development dependency (or optional).

## Migration notes

If you are upgrading from version `1.0.0` or earlier:
1. Update your import statements to use `from app.` instead of `from src.`.
2. If you use custom scripts that call the module directly, change `python -m src.entrypoints.cli` to `python -m app.entrypoints.cli` or simply `python -m app` for the default CLI.
3. If you use the API, update the uvicorn command: `uvicorn app.entrypoints.api:app`.
