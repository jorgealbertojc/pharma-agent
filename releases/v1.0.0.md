# 1.0.0 - First stable release of Pharma Agent

This is the **first stable release** of the Pharma Agent project, a fully functional AI-powered assistant for pharmacy operations. The agent integrates RAG, inventory management, conversation memory, and upsell suggestions into a single conversational interface.

## What's new

### Complete Agent System
- **LangGraph agent** with four interconnected nodes: RAG retrieval, inventory search, upsell suggestion, and response generation.
- **Conversation memory** with Redis persistence and token/message limits.
- **Real-time inventory** from Google Sheets with Redis caching to avoid API quota exhaustion.
- **RAG pipeline** with Pinecone local index and Ollama embeddings (supports similarity, MMR, and threshold-based retrieval).

### Entrypoints
- **FastAPI REST API** with `/health` and `/query` endpoints, CORS support, and structured error responses.
- **CLI** with interactive mode and single-query support (`--question`).

### Core Foundation
- **Pydantic models** for requests/responses with field validation.
- **Custom exception hierarchy** for consistent error handling across all modules.
- **Centralized configuration** via `pydantic-settings` with environment variable support.

### Tools Module
- **SearchInventory**: Query inventory by name, code, brand, or category.
- **SearchDocs**: Retrieve information from indexed documents (RAG).
- **SuggestUpsell**: Generate complementary product suggestions with safety-first fallback logic.
- **ResponseFormatter**: Unified formatting for Markdown, JSON, and plain text.

### Testing
- Comprehensive **unit and integration tests** for all modules.
- Integration tests use **real services** (Ollama, Pinecone, Google Sheets) and are autonomous.
- CI/CD ready (GitLab and GitHub).

## Changed since 0.0.4
- **Agent graph** refactored to accept `AgentNodes` instance (dependency injection).
- **Graph configuration** now requires `thread_id` for checkpointer.
- **CLI** now uses `capsys` and `monkeypatch` for reliable test output capture.
- **API validation** returns 400 instead of 422 for validation errors.
- **Memory validation** for empty questions in `_process_question()`.

## Fixed
- `ChatOllama` attribute assignment issues in tests (patched at class level).
- Pinecone cleanup and test isolation.
- Empty query handling in agent nodes.
- Model validation for whitespace-only questions.

## Documentation
- **README.md** fully updated with installation, configuration, usage, and project structure.
- **Release notes** for all previous versions (`v0.0.1` to `v0.0.4`).
