# 0.0.3 - Agent module with LangGraph integration, tools, and conversation memory

This release completes the core agent functionality, integrating all previous modules (RAG, Inventory, Memory, Tools) into a cohesive conversational agent using LangGraph. The agent can now answer pharmacy-related questions, search inventory, suggest upsell products, and maintain conversation history.

## Added

### Agent Module (`src/agent/`)

- **State Management (`state.py`)**: Defines `AgentState` TypedDict with fields for messages, question, context, inventory results, suggestions, final answer, error handling, control flow, and iteration counter. Includes helper functions for state initialization and safe message appending.
- **Nodes (`nodes.py`)**: Implements `AgentNodes` class with dependency injection for Retriever (RAG) and Inventory. Each node encapsulates a specific responsibility:
  - `retrieve_docs_node`: Retrieves relevant document fragments via RAG.
  - `search_inventory_node`: Queries inventory for medications matching the user's question.
  - `suggest_upsell_node`: Generates complementary product suggestions based on the requested medication.
  - `generate_response_node`: Uses ChatOllama with a structured prompt (including history, context, inventory results, and suggestions) to produce the final answer.
  - `should_continue`: Routing function to decide whether to finish or continue the graph execution.
- **Graph (`graph.py`)**: Builds the LangGraph workflow connecting all nodes sequentially (retrieve_docs → search_inventory → suggest_upsell → generate_response) with a conditional edge after response generation. Uses `MemorySaver` for conversation state persistence.
- **Executor (`executor.py`)**: Provides `AgentExecutor` class with an interactive loop for user conversations. Handles input/output, state management, and graceful exit with `Ctrl+C` or `salir`/`exit`/`quit` commands.
- **Integration Tests**: Complete test suite covering state, nodes, graph, and executor with real services (no mocks). Tests are autonomous, cleaning Pinecone before each run and using real inventory from Google Sheets.

### Tools Module Updates

- **SearchDocs**: Enhanced with JSON output support and improved error handling.
- **SearchInventory**: Added category-based search and formatted output options.
- **SuggestUpsell**: Implemented fallback logic with generic safe products (Electrolit, purified water, juice) when no related items are found.

### Core Module Completions

- **Agent State**: Fully typed with `TypedDict` and `Annotated` for automatic message accumulation.
- **Dependency Injection**: All agent nodes receive dependencies (Retriever, Inventory) through constructor injection, ensuring testability and decoupling.

## Fixed

- **LangGraph Checkpoint**: Fixed `MemorySaver` import from `langgraph.checkpoint.memory` and added required `thread_id` configuration for `invoke()` calls.
- **Graph Architecture**: Resolved architectural mismatch by refactoring `graph.py` to accept an `AgentNodes` instance instead of importing standalone node functions.
- **Empty Input Handling**: `_process_question()` now ignores empty questions, preventing unnecessary graph invocations and error messages.
- **Pydantic v2 Compatibility**: Fixed attribute assignment issues in tests by patching `ChatOllama.invoke` at class level instead of instance level.

## Changed

- **Graph Export**: Removed global `agent_graph` instance; `build_agent_graph(nodes)` now requires an `AgentNodes` instance, promoting explicit dependency management.
- **Tests**: All integration tests now use real services (Ollama, Pinecone, Google Sheets) and clean up after themselves, ensuring no state leakage between tests.
