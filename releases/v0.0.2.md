# 0.0.2 - Tools module for inventory search, document search, and upsell suggestions

This release adds a complete set of tools for the pharmacy assistant agent, enabling inventory queries, document retrieval (RAG), and intelligent upsell recommendations. All tools are fully tested with integration suites.

## Added

### Tools Module (`src/tools/`)

- **ResponseFormatter**: Unified output formatting for Markdown, JSON, and plain text.
  - Convert strings, dicts, lists, and `Medicamento` objects to structured Markdown tables or lists.
  - Serialize any data to JSON with configurable indentation and ASCII options.
  - Format final agent responses with optional sources.
  - Standardized error messages.

- **SearchInventory**: Query the inventory by name, code, brand, or category.
  - `search()`: Returns raw `Medicamento` objects.
  - `search_by_category()`: Filters by exact category (case-insensitive).
  - `search_and_format()`: Returns results as Markdown table or list with optional `max_items` limit.
  - `search_by_category_and_format()`: Same for category-based searches.
  - Fully integrated with `ResponseFormatter`.

- **SearchDocs**: Query external documents (books, prospectuses, guides) via RAG.
  - `search()`: Returns raw text fragments from the retriever.
  - `search_as_context()`: Concatenates fragments into a single context string.
  - `search_and_format()`: Returns results as Markdown viñetas or JSON, with `max_items` limit.
  - Uses the existing `Retriever` (RAG) and `ResponseFormatter`.

- **SuggestUpsell**: Suggest complementary products based on the medication being requested.
  - `suggest()`: Finds related products by category, active ingredient, or brand.
  - Limits suggestions to a maximum of 3 products.
  - Fallback logic: if no related products found, recommends safe generic items (Electrolit, purified water, juice).
  - All recommendations are formatted in Markdown using `ResponseFormatter`.
  - **Safety-first design**: no AI hallucinations; suggestions are always based on real inventory data.

### Integration Tests

- **`test_search_inventory.py`**: Covers search by name, code, brand, category, empty queries, and formatted outputs.
- **`test_search_docs.py`**: Each test autonomously cleans Pinecone, indexes a test document, and runs queries.
- **`test_suggest_upsell.py`**: Tests existing product suggestions, non-existent product fallback, Markdown formatting, exclusion of base product, and max items limit.
- All integration tests are isolated and do not interfere with each other.

### Dependency Updates

- Added `gspread` and `google-auth` for Google Sheets integration (already used in `inventory` module).

## Fixed

- **Retriever**: Enforced `SearchType` enum usage to prevent `AttributeError` when passing strings.
- **Tests**: Improved test autonomy by cleaning Pinecone before each `search_docs` test and using real inventory from Google Sheets for `search_inventory` and `suggest_upsell`.
- **Inventory Client**: Enhanced header normalization (strip spaces, handle duplicates) and added proper error logging.

## Changed

- **Error handling**: Improved logging for failed rows in inventory parsing.
- **Code quality**: All tools follow Clean Code principles, with dependency injection and clear separation of concerns.
