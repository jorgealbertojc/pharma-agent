# pharma-agent

AI-powered pharmacy assistant.

## Inicio rápido

1. Copia `.env.example` a `.env` y ajusta las variables.
2. Verifica que la configuración se carga correctamente:

```bash
uv run python -m tools.check_settings
```

Consulta [docs/01-python/README.md](docs/01-python/README.md) para más detalles sobre el entorno de desarrollo Python.
